# Research Notes — OHT, AMHS, Routing, and Reinforcement Learning

## Introduction / 연구를 시작한 이유

반도체 공장 안의 물류는 일반적인 배송 최단경로 문제와 다르다. 전자 제품을 만들기 위한 웨이퍼는 여러 공정을 반복해서 이동하며, 웨이퍼 용기(FOUP)를 싣는 천장형 운반차(OHT)는 좁은 레일과 교차로를 공유한다. 차량 한 대의 이동거리를 줄여도 다른 차량이 장시간 기다린다면 공장 전체의 운송 작업 완료 수는 감소할 수 있다.

이번 모델에서는 FAB의 구조를 실제 도면 그대로 재현하려 하기보다, 레일 공유와 자원 점유라는 문제를 분리해서 정량적으로 분석했다.

### Terminology

- **FAB (Fabrication facility)**: 반도체 웨이퍼가 공정 장비 사이를 이동하며 제조되는 공장.
- **OHT (Overhead Hoist Transport)**: 천장 레일을 사용하는 웨이퍼 용기 운반 장치.
- **FOUP (Front Opening Unified Pod)**: 웨이퍼를 보관·운반하는 밀폐형 용기.
- **AMHS (Automated Material Handling System)**: 운송·저장·배차 등을 포함하는 자동화된 물류 시스템.
- **Throughput**: 주어진 시간 동안 완료한 운송 작업 수.

## Discrete-event logic and common random numbers

운송 요청은 생성된 난수에 따라 발생하고, OHT는 차례대로 차량 배정과 이동을 수행한다. 선택한 정책의 비용과 자원 점유 상태가 경로를 결정한다. 실험 결과는 Python 시뮬레이터의 산출물을 기록한 CSV에서 가져왔다.

정책마다 완전히 다른 운송 요청을 사용하면 운이 좋은 정책이 이길 수 있다. 이를 줄이기 위해 같은 시나리오에서는 동일한 난수 시드로 생성된 운송 요청을 사용해 대응표본을 구성했다. 학습용 시드는 평가용 시드와 분리했다.

## Dijkstra versus congestion-aware routing

Dijkstra 알고리즘은 그래프 각 링크의 비용을 합산해 출발지에서 목적지까지 비용이 가장 작은 경로를 찾는다. 정적 최단경로는 차량 하나에는 효율적일 수 있지만, 여러 차량이 동시에 사용하는 교차로를 고려하지 못할 수 있다. 혼잡 대응형 정책은 점유·예약 상황과 안전 제약을 확인해 이동 경로를 갱신한다.

## Reservation architecture

### Full-route atomic reservation
한 차량이 출발 전에 전체 예정 경로를 선점한다. 차량이 아직 도착하지 않은 교차로도 다른 차량이 사용하기 어려울 수 있어 통행 가능 용량이 보수적으로 줄어든다.

### Next-segment partial reservation
진입하려는 다음 노드 및 방향성 링크가 사용 가능한지 검사해 해당 구간만 예약한다. 이미 지난 구간은 회수되며 다른 차량이 사용할 수 있다. 단, 소수의 교차로에서 차량들이 서로 기다리면 순환대기 위험이 생길 수 있다.

## Wait-for Graph

차량 A가 차량 B가 점유한 구간을 기다린다면 A→B 간선을, B가 C를 기다린다면 B→C 간선을 대기 그래프에 추가한다. A→B→C→A와 같이 닫힌 방향성 사이클이 관측되면 교착 가능성을 검사해야 한다. 시뮬레이터에서 사용한 국소 순환 회피 제약은 산업 현장에서 모든 상황의 교착이 절대로 없다는 증명이 아니다.

## Reinforcement Learning / Q-learning

학습은 특정 상태에서 어떤 행동을 선택했을 때 장기 보상이 어떻게 되는지를 평가하는 데 사용했다. 이 연구는 거대 언어모델이나 CNN을 사용해 차량을 제어하지 않는다. Q-learning은 테이블에 상태-행동 평가값을 저장하는 전통적인 강화학습 기법이다.

일반적인 갱신식은 다음과 같다.

```text
Q(s,a) <- Q(s,a) + alpha * [r + gamma * max Q(s',a') - Q(s,a)]
```

여기서 `s`는 위치·목적지 구역·상황·활성 차량 수준을 요약한 상태, `a`는 진입 가능한 다음 링크, `r`은 이동·대기 등과 연결된 보상이다. `alpha`는 학습률, `gamma`는 할인율이다. 실험에서는 학습률 0.22와 할인율 0.87을 사용했다.

경로를 크게 돌아가는 행동은 위험하거나 느릴 수 있으므로 학습 정책에도 안전한 후보 행동과 우회거리 제한을 적용했다. 이 조건은 학습을 더 어렵게 만들지만, 학습과 안전 제약을 분리해 분석하도록 한다.

**중요한 대조실험:** 동일한 경로 제약과 선택 구조를 갖되 Q값을 학습하지 않은 정책을 별도로 평가했다. 이렇게 해야 학습한 Q값 때문에 달라진 효과를 자원 예약 자체의 효과와 구분할 수 있다.

## Statistics / paired bootstrap and Holm correction

시드 i별 차이는 `Delta_i = outcome(policy A, seed i) - outcome(policy B, seed i)`로 정의했다. 관측된 쌍을 재표집해 95% 부트스트랩 신뢰구간을 계산했고, 부호검정 결과는 여러 비교를 고려해 Holm 보정을 적용했다.

완료 작업 수는 25분이라는 동일한 시간에서 계산했다. 완료된 운송만의 평균 리드타임은 완료되지 못한 작업이 누락된다는 선택 편향이 생길 수 있으므로 주 해석에서는 완료 건수를 우선했다.

## Bottom line / 정리

실험에서 가장 큰 효과는 학습 여부보다 레일 자원 예약 구조를 바꾸는 데서 나타났다. Q-learning이 유의미한 추가 효과를 보인 조건도 있었지만, 그 차이는 작았고 다른 조건에서는 유지되지 않았다. 따라서 이 연구는 'AI가 무조건 최적'이라는 결과가 아니라, **산업공학적 자원 제약과 알고리즘 검증이 왜 중요한지 보여주는 합성 시뮬레이션 사례**다.
